- Project website (`apps/docs`), built with Blume: landing page, docs and blog, English and German locales.
- `nap_tool` app (`apps/nap_tool`): downloads grid expansion plan documents from VNBdigital, extracts their tables with several tools and lets reviewers accept normalized CSV output ([#2](https://github.com/gridAhead/gridAhead/pull/2)).
- gridAhead logo, favicon and Apple touch icon; partner and funder logos on the website and in the README.
- Cloudflare Wrangler configuration for deploying the website.
- This changelog.
