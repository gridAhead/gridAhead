Distribution grid operators in Germany are required [by law](https://www.gesetze-im-internet.de/enwg_2005/__14d.html) to publish grid expansions plans every two years.
This usually means they publish PDFs with unstructured or semi-structured data. gridAhead plans to collect, maintain and publish
- data pipelines 
- consolidated data results

so the public can more easily make use of those already-published plans.

## Current state of the project

This repository is currently being constructed, as the first modules are being added.
We currently do not publish any data.

## Who is behind it

gridAhead is a cooperation of the [Reiner Lemoine Institute](https://reiner-lemoine-institut.de/) and [Goal100](https://goal100.org/). See our [announcement post](/blog/2026-11-15-introducing-gridahead) for more info and background.
